# Как это работает: VLESS + XHTTP + Reality

Этот документ объясняет техническую схему, которую использует форк по умолчанию. Он предназначен для тех, кто хочет понять, что происходит «под капотом», и почему выбраны именно эти настройки.

## 🖼️ Схема рукопожатия

```text
┌─────────────┐           ┌──────────────────────────────────────┐           ┌─────────────┐
│   Клиент    │           │           Сервер (VPS)               │           │   Интернет  │
| v2rayN и т.д)│          │                                      │           │             │
└──────┬──────┘           └──────────────────┬───────────────────┘           └──────┬──────┘
       │                                     │                                      │
       │ 1. TLS ClientHello (SNI: karkkainen.com)                                   │
       │ ───────────────────────────────────>│                                      │
       │                                     │ 2. Reality проверяет SNI             │
       │                                     │    и отдаёт сертификат               │
       │ 3. TLS ServerHello                  │    (валидный для karkkainen.com)     │
       │ <───────────────────────────────────│                                      │
       │                                     │                                      │
       │ 4. VLESS-запрос (UUID + XHTTP)      │                                      │
       │   ⚠️ Flow: только с VLESS Encryption│                                      │
       │ ───────────────────────────────────>│                                      │
       │                                     │ 5. Xray проверяет UUID,              │
       │                                     │    распаковывает XHTTP               │
       │                                     │                                      │
       │                                     │ 6. Запрос к целевому сайту           │
       │                                     │ ────────────────────────────────────>│
       │                                     │                                      │
       │                                     │ 7. Ответ от сайта                    │
       │                                     │ <────────────────────────────────────│
       │                                     │                                      │
       │ 8. Ответ клиенту (через XHTTP)      │                                      │
       │ <───────────────────────────────────│                                      │
       │                                     │                                      │
